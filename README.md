# soko-timers

A small single page app with a pomodoro timer and the ability to add your own custom times. 
* The status of each timer is shown in the list of timers so that you don't have to switch to each timer to see if its finished or not.
* Double-clicking on a timer in the timer list will reset it
* When a timer finishes it will be indicated in the timer list and three (3) subtle beeps will sound. The default pomodoro timer has a more audible sound.

## Pomodoro timer
While the custom timers only have start/stop/pause the pomodoro timer has two built in timers. First a 25 minute focus window and a 5 minute pause window.
